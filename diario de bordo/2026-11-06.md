### Integracao preparada

O fluxo planejado e:

```text
Label Flow no AKS
  -> Azure Files: dataset YOLO
  -> SeaweedFS/S3 no host GPU
  -> Ultralytics Adapter
  -> GPU NVIDIA
  -> artefatos e status do treinamento
```

O FTMS oficial nao possui endpoint publico de upload de dataset no contrato
observado. O dataset precisa ser publicado no SeaweedFS e referenciado por uma
URI como:

```text
seaweedfs://tao-storage/data/label-flow/<dataset_uid>
```

### Bloqueio restante

Os egress do AKS foram criados, mas o host GPU ainda precisa executar a nova
versao do wrapper para abrir as portas do adapter e do S3.

Executar no host GPU:

```bash
git pull
./tao-ftms up-all
```

Depois disso, validar:

```bash
kubectl -n label-flow get service tao-ultralytics-gpu \
  -o jsonpath='{.status.conditions}{"\\n"}'
kubectl -n label-flow get service tao-seaweedfs-s3 \
  -o jsonpath='{.status.conditions}{"\\n"}'
```

O backend do Label Flow ainda nao foi alterado para submeter treinamentos ao
TAO. Essa etapa deve ser feita somente depois que o adapter e o S3 estiverem
acessiveis, para evitar apontar o treinamento para endpoints indisponiveis.
