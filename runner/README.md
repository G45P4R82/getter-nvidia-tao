# GitHub Actions Runner

Dockerized self-hosted runner for the TAO training machine.

The runner intentionally does not mount `/var/run/docker.sock`, does not use
privileged mode, and does not receive GPU devices. Workflows call the TAO FTMS
API; the FTMS itself owns Docker and GPU job execution.

## Start

Obtain a short-lived repository registration token from GitHub, then run:

```bash
cd runner
export REPO_URL=https://github.com/G45P4R82/getter-nvidia-tao
export RUNNER_TOKEN='short-lived-registration-token'
export RUNNER_NAME=tao-ftms-docker
export RUNNER_LABELS=tao-ftms
docker compose up -d --build
```

The registration token is not the NGC key. It is generated by GitHub for
registering this runner and should not be committed.

Check status:

```bash
docker compose ps
```

The workflow uses `host.docker.internal` for the FTMS endpoint when the runner
is inside Docker. Set the repository variable `TAO_BASE_URL` to:

```text
http://host.docker.internal:8090
```

The workflow runs on `main` pushes and manual dispatch only. Do not add
Pull Request execution back while this runner is connected to a public
repository.
